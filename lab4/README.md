# Лабораторная работа 4: Архитектура приложения с разделением слоёв

## Цель работы
Изучение принципов чистой архитектуры backend-приложений, разделения ответственности между компонентами, внедрения зависимостей (Dependency Injection) и конфигурации через переменные окружения.

## Задачи
1. **Рефакторинг**: разделение монолитного кода на слои:
   - **Handler / Router** (обработчики HTTP-запросов)
   - **Service** (бизнес-логика и правила)
   - **Repository** (слой работы с данными)
2. **Dependency Injection**: использование механизма `Depends` в FastAPI.
3. **Конфигурация** приложения.

## Структура проекта
~~~text
lab4/
├── app/
│   ├── __init__.py
│   ├── database.py       # Конфигурация базы данных
│   ├── models.py         # ORM-модели
│   ├── schemas.py        # Pydantic схемы валидации
│   ├── repository.py     # Слой работы с данными
│   ├── services.py       # Слой бизнес-логики
│   └── routers.py        # Маршрутизаторы и эндпоинты
├── screenshots/          # Скриншоты работы приложения
├── main.py               # Точка входа в приложение
├── requirements.txt      # Зависимости проекта
├── Dockerfile            # Конфигурация Docker
└── docker-compose.yml    # Конфигурация Docker Compose
~~~

## Запуск проекта через Docker
1. Соберите и запустите контейнер:
~~~bash
docker compose up --build
~~~
2. Откройте документацию API в браузере:
   - **Swagger UI**: [http://localhost:8000/docs](http://localhost:8000/docs)
