# Лабораторная работа №1: Настройка окружения и первый HTTP-сервер

## Цель работы
Настроить окружение разработки, создать простой HTTP-сервер, упаковать приложение в Docker-контейнер и настроить его запуск с помощью `docker-compose.yml`.

## Стек технологий
* **Язык программирования:** Python 3.11
* **Фреймворк:** FastAPI + Uvicorn
* **Контейнеризация:** Docker, Docker Compose

## Структура проекта
* `app.py` — код веб-сервера с эндпоинтами `/` и `/health`.
* `requirements.txt` — зависимости проекта (`fastapi`, `uvicorn`).
* `Dockerfile` — конфигурация сборки Docker-образа на базе `python:3.11-slim`.
* `docker-compose.yml` — описание сервиса для запуска контейнера с пробросом порта `8000:8000`.

## Инструкция по запуску
1. Перейти в директорию проекта:
   ```bash
   cd lab1
   ```
2. Собрать образ и запустить контейнер:
   ```bash
   docker compose up --build
   ```
3. Открыть в браузере `http://localhost:8000`.

## Результаты работы
* Приложение успешно собрано и запущено в Docker-контейнере.
* Сервер корректно обрабатывает HTTP GET-запросы и возвращает JSON-ответ.
